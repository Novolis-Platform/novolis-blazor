# Novolis.Blazor.Components

Graphical Profile chrome for Blazor hosts: shell, cards, dialogs, lists, and articles.

```powershell
dotnet add package Novolis.Blazor.Components
```

Link `Novolis.Blazor.GraphicalProfile.GraphicalProfile.StylesheetHref` and `Chrome.StylesheetHref`, then use `AppChrome`, `SectionCard`, `LinkCard`, `ConfirmDialog`, `ArticleView`, and `EntryList`.
