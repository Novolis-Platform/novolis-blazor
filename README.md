# novolis-blazor

Reusable Blazor packages for Novolis hosts:

- `Novolis.Blazor.GraphicalProfile` — required chrome stylesheet and `--ngp-*` tokens
- `Novolis.Blazor.Components` — shell, cards, dialogs, lists, and articles on those tokens
- `Novolis.Blazor.Mermaid` — Mermaid component backed by Novolis headless markup rendering

See [getting started](docs/getting-started.md), [design](docs/design.md), and [release](docs/release.md).
